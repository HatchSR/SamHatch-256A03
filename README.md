# Django Event Registration Web Application

This is a Django-based web server designed to handle user registration for events. The application supports role-based access and includes administrative tools for managing events and users.

## Features

### Admin Capabilities

- Create, edit, and delete events  
- View all registered users and their assigned roles  
- Generate detailed registration reports via the **Admin Event View**  
- Access a complete history of all events, including past ones

### User Capabilities

- Register for upcoming events  
- View only current and future events (past events are hidden)

## Notes

To view who is registered for specific events, administrators should navigate to the **Admin Event View** and select **Generate Report**.
